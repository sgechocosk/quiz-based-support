# Quiz-based Support

コードベースを調べて質問に答える代わりに、**穴埋めクイズ**で「システムとコードの理解」を促す VS Code 拡張です。

## 動作の流れ
1. サイドバー「Quiz Support」で質問・要望を入力(例: 「認証のフローを理解したい」)。
2. エージェントがワークスペースを調査(ハイブリッド検索 BM25+ベクトル / grep / read_file / outline / LSP の定義・参照)。
3. **実際に読んだコードだけ**を根拠に、問題を生成。
   - LLM は「どの行のどの文字列を空欄にするか」だけを指定し、問題のコードはシステムが実ファイルから組み立てる(書き写しの食い違いで問題が落ちない。空白ゆれ・行番号ずれも吸収)
   - 読解: 実コードの一部を空欄化(正解で埋めると必ず原文に戻る)
   - 実装: 変更後のコードから、変更した行を必ず含めて空欄化(構文検査つき)
   - 構造クイズ: LSP から決定的に作る選択問題(呼び出し元・定義ファイル)
   - 不合格の問題は理由と実際の行内容を添えて作り直させる(合格した問題は残す)
   - 「自動」モードで質問が実装・修正の依頼(「〜を追加したい」「〜にしたい」等)なら、実装問題を最低1問必須にする。実装の前に理解すべき重要なコード・設計があれば読解も最大2問含める(読解→実装の順)。作れなかった場合はその旨を表示
   - 新しく作るメソッド・変数などの名前は出題側で決め、「この問題で新しく作る名前」として解答前に表示する。名前そのものの空欄や、どこにも定義の無い関数を答えにする空欄は除外(推測不能な問題を出さない)
   - 表示量の調整: 問題の範囲は空欄・変更行の前後3行まで自動で切り詰め、途中の無関係な行は「N行省略」に折りたたむ(クリックで展開)。採点後の完成形は変更の周辺だけの差分(+/-)で表示
4. 解答前に「課題文(実装なら仕様、読解なら読みどころ)」と「参考にするコード」へのリンクを表示。
5. 空欄は**選択式**(正解1つ + 誤答3つ)。選んだ選択肢がコード中の空欄にはまって表示されるので、前後とのつながりを見ながら選べる → 段階ヒント(概念 → 考え方 → 手がかりの場所 → 誤りの選択肢を1つ消す) → 採点。
   - 誤答は「コードベースを読めば誤りと判断できる」もの(実在する似た名前の別の関数・変数、境界条件の違い、条件の反転、引数の取り違えなど)。コードベースに無い名前を含む誤答・正解と同じ書き方の誤答・長さで見分けがつく誤答は除外し、足りなければ正解の一部を実在する名前や反対の演算子に変えた誤答で補う
   - 採点後は、正解の理由と、自分が選んだ誤答が「なぜ違うか」だけを表示(他の誤答の解説は情報量を抑えるため出さない)
   - 先に予想するメモは任意(開いたときだけ入力欄を表示)
   - 解答前に見える文章(目標・課題文・ヒント・概念タグ・手がかり)は答えを含まないか機械判定し、漏れていれば LLM に書き直させ、それでも直らなければ伏せ字に置き換える
   - 手がかりの場所は実在し、その行に答えが書かれていないものだけを表示
   - 正解・解説は採点まで画面に渡りません。採点後は空欄ごとの「なぜ」、範囲の解説、実装問題では完成形のコードを表示
6. 「実装」問題は確認ダイアログの後、正解コードをファイルへ反映(Undo 可)。
7. 学習記録(概念別正答率・Leitner 方式の復習カード)は workspaceState に保存。

## セットアップ
- コマンド「Quiz Support: Set OpenAI API Key」またはサイドバーの「APIキー」で設定(SecretStorage に保存)。
- キー無しでもキーワード索引(BM25)は自動作成されます。意味検索(埋め込み)は「インデックス」から見積もりを確認して有効化。

## 設定
| 設定 | 既定 | 内容 |
|---|---|---|
| quizSupport.learnerLevel | intermediate | 学習レベル。beginner(初学者・学生) / intermediate(実務エンジニア) / advanced(高度・独自技術の定着)。問題の難しさ・用語の言い換え・解説の細かさが変わる。初回はサイドバーで選択、以後もサイドバー上部で変更可 |
| quizSupport.model | gpt-5-mini | 生成モデル |
| quizSupport.reasoningEffort | auto | 推論強度。auto は gpt-6-luna 等「ツールと併用不可」のモデルで自動的に none へ切替 |
| quizSupport.embeddingModel | text-embedding-3-small | 埋め込みモデル |
| quizSupport.baseUrl | OpenAI | OpenAI互換エンドポイント |
| quizSupport.maxAgentSteps | 8 | 調査の最大ステップ |
| quizSupport.minSimilarity | – | ベクトルのみ一致の下限 |
| quizSupport.structureQuestions | – | LSP 構造クイズ |
| quizSupport.autoEmbedMaxTokens | – | 自動埋め込みの上限 |
| quizSupport.maxFiles | – | 索引対象の最大ファイル数 |

## 開発
```
npm install
npm run test:unit      # ユニット/E2E(偽OpenAI)
npm run check-types && npm run lint
npm run compile        # esbuild(依存を全て同梱)
F5                     # Extension Development Host
npm run package:vsix   # .vsix 作成
```

## 既知の制限
- AST チャンク分割は ts/tsx/js/java のみ。他言語は行ベース分割。
- 旧版の `vector-index` は使用しません(新形式は `index-v2`)。再索引は自動。
- 実 VS Code・実 OpenAI API での通し検証は開発環境では未実施です。
